## 🗄️ Зміни в базі даних

### Book модель (нові поля)
```sql
externalId       String?         @unique
externalSource   String?         -- 'google_books', 'open_library', 'gutenberg'
externalUrl      String?
isbn             String?
description      String?         @db.Text
pageCount        Int?
publishedDate    String?
lastSyncedAt     DateTime?
```

### SyncLog модель (нова)
```sql
model SyncLog {
  id          Int      @id @default(autoincrement())
  source      String   -- джерело синхронізації
  status      String   -- 'success', 'error', 'partial'
  booksAdded  Int      @default(0)
  booksUpdated Int     @default(0)
  errors      String?  @db.Text
  startedAt   DateTime @default(now())
  completedAt DateTime?
  duration    Int?     -- в мілісекундах
}
```

## 📡 API Ендпоінти

### Синхронізація
- `POST /api/sync/source` - Синхронізація з конкретним джерелом
- `POST /api/sync/full` - Повна синхронізація з усіх джерел
- `POST /api/update-existing` - Оновлення існуючих книг

### Пошук та моніторинг
- `GET /api/search` - Пошук у всіх джерелах
- `GET /api/logs` - Логи синхронізації
- `GET /api/stats` - Статистика синхронізації
- `GET /api/health` - Перевірка здоров'я зовнішніх API

### Управління планувальником
- `GET /api/scheduler/status` - Статус завдань
- `POST /api/scheduler/control` - Запуск/зупинка завдань
