## Потік даних

### 1. Автоматична синхронізація
```
Планувальник → SchedulerService → ExternalBookService → Зовнішні API
     ↓
База даних ← SyncLog ← Результати синхронізації
```

### 2. Ручна синхронізація
```
Клієнт → API Gateway → SyncController → ExternalBookService → Зовнішні API
  ↓
База даних ← SyncLog ← Результати синхронізації
```

### 3. Пошук книг
```
Клієнт → API Gateway → SyncController → ExternalBookService → Зовнішні API
  ↓
Результати пошуку (без збереження)
```

## Компоненти системи

### 🎯 ExternalBookService
- **Google Books API**: Пошук сучасних книг
- **Open Library API**: Класична література
- **Project Gutenberg API**: Безкоштовні класичні книги

### ⏰ SchedulerService
- **Щоденна синхронізація**: Google Books (2:00)
- **Щотижнева синхронізація**: Open Library (3:00, неділя)
- **Щомісячна синхронізація**: Project Gutenberg (4:00, 1 число)
- **Щогодинна перевірка**: Популярні книги

### 📊 SyncController
- Ручна синхронізація
- Пошук у всіх джерелах
- Управління планувальником
- Моніторинг та статистика

### 🗄️ База даних
- **Books**: Розширена модель з полями для зовнішніх джерел
- **SyncLog**: Логування всіх операцій синхронізації
- **Users**: Користувачі системи

## API Ендпоінти

### Синхронізація
- `POST /api/sync/source` - Синхронізація з конкретним джерелом
- `POST /api/sync/full` - Повна синхронізація
- `POST /api/update-existing` - Оновлення існуючих книг

### Пошук та моніторинг
- `GET /api/search` - Пошук у всіх джерелах
- `GET /api/logs` - Логи синхронізації
- `GET /api/stats` - Статистика
- `GET /api/health` - Перевірка здоров'я API

### Управління
- `GET /api/scheduler/status` - Статус планувальника
- `POST /api/scheduler/control` - Управління завданнями

## Безпека

### 🔐 Авторизація
- JWT токени для всіх API ендпоінтів
- Middleware для перевірки прав доступу

### 🛡️ Захист від зловживань
- Rate limiting для API запитів
- Валідація вхідних даних
- Обробка помилок та логування

### 📝 Логування
- Всі операції синхронізації логуються
- Зберігання помилок та статистики
- Моніторинг здоров'я зовнішніх API

## Масштабування

### 🔄 Горизонтальне масштабування
- Можливість додавання нових джерел
- Розширення планувальника завдань
- Додавання нових типів синхронізації

### 📈 Вертикальне масштабування

- Кешування результатів
- Пакетна обробка даних

### 🚨 Алерти
